# Лабораторная работа: Циклы и ветвление

## Автор

Чупин Артем (Вариант 34)

## Цель

Освоение цикла for и операторов ветвления.

## Описание

Программа вычисляет доли отражённой и прошедшей световой мощности при различных значениях.

## Исходные данные

- Показатель преломления: 1.5
- Показатель преломления с воздухом: 1.0
- Углы падения вводятся пользователем

## Ожидаемые результаты

Программа выводит три значения:

- α: угол падения
- R: Отраженная световая мощность
- T: Прошедшая световая мощность
